refactor(bls): production hardening and resource optimization for Broken Link Scanner

This commit addresses several critical logic and UX issues in the Broken Link Scanner module to ensure stability and efficiency.

Backend Improvements:
- Context Propagation: Implemented full context propagation from handlers down to service worker loops.
- Early Abort: Added support for early task cancellation using ctx.Done(), allowing the server to reclaim CPU and network resources immediately when a client disconnects or aborts the scan.
- Host Extraction: Replaced error-prone manual offset-based host extraction with robust url.Parse() implementation, supporting both http and https protocols correctly.
- Code Standards: Standardized hostname comparisons using strings.EqualFold for better Go-lang performance and consistency.

Frontend Enhancements:
- Utility Migration: Removed local escapeHTML implementation and migrated to shared utils/index.js for better maintainability.
- UX Overhaul: Refactored the progress indicator. Replaced the static, non-updating progress bar with a dynamic spinner and descriptive status labels ("Đang thu thập và phân tích liên kết...") to provide better user feedback during synchronous API execution.
- UI Stability: Fixed minor syntax errors and ensured proper UI state transitions during scan lifecycle (start, cancel, error).
